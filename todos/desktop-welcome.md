# 首次启动欢迎页

状态：第 1–3 项已本地实现，首次启动入口已接入；第 4 项离线验收已通过，原生 WebView 实测待完成；当前分支 codex/desktop-i18n。随当前分支交付 PR，原生平台验收继续保留待完成。

## 产品行为

首次启动使用铺满窗口的独立欢迎页，保留原生窗口控制与顶部拖动区，隐藏常规侧栏、导航与首页。仅配置语言、显示模式（跟随系统/浅色/深色）和预设主题；即时切换与预览，点击“开始使用”进入正常界面，后续仍可在设置修改。不加入登录、安装等流程。

完成状态独立于语言/主题偏好。欢迎页开始前记录 pending，完成后记录 complete；中途关闭后继续引导，不能将引导期间保存的偏好误认为旧用户。没有标记时，已有语言/外观偏好或已确认存在的实例/账户视为旧用户，保留原配置并跳过。Runtime 数据尚未确认或读取失败时先不展示欢迎页、不写完成标记，留待下次确认；不能将失败当空数据。存储失败不阻止进入首页，提示本次选择可能无法保留。

## 识别边界

旧版没有专门的欢迎页标记，不能仅凭一个新键不存在就断言“首次使用”。第 1 项只实现可测试状态规则；第 3 项接入真实偏好及 Runtime 实例/账户读取。若用户清除了全部本地偏好且数据也为空，会被视为新用户。语言/主题继续使用现有存储键，不另存一套配置。

## 离线验收结论

welcome.browser.mjs 使用独立浏览器存储、本地假 Runtime 与假 Shell，屏蔽外网；确认欢迎期间只有健康/账户列表/实例列表读取，完成后才挂载业务页面。已有账户进入正常界面时允许唯一的假账户 verify POST；没有登录、安装、导出或删除请求。覆盖数据读取失败不误判新用户、任一来源已有数据时跳过、存储不可读时进入主界面、完成标记写入失败仍进入主界面并可关闭提示。

48 组主题/模式/语言/尺寸组合通过，使用键盘选择语言、Escape 返回触发器，检查无横向溢出和完成按钮可滚动到达；查看英文 900px 深色整页与 620px 滚动末端截图，窄窗使用单列与页面滚动。既有 settings-language 浏览器回归通过。原生窗口控制、透明拖动区与真实存储仍需维护者在目标系统验收，不能用无头 Edge 结果替代。
