# Anvil

一个轻量的 Minecraft Java 版启动器，希望让游戏安装、模组和光影管理更简单。

项目正在开发中，功能和交互设计仍在完善，欢迎试用和反馈。

## 试用

在 [Releases](https://github.com/mivinci/Anvil/releases) 下载适合你系统的桌面内测包。

遇到问题或有功能建议，欢迎提交 [Issue](https://github.com/mivinci/Anvil/issues)。

## 从源码运行

需要 Rust 1.90+、Node.js 22.17+ 和 [Tauri 平台依赖](https://v2.tauri.app/start/prerequisites/)。

```sh
npm install
npm run desktop:dev
```
