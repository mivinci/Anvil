# 持续跟随目标契约

本契约是 AI 玩家首个纵向场景的接入边界。`anvil-agent::contract` 已提供纯同步的目标接纳、阶段转换、决策来源校验与动作所有权原型；该模块不调度游戏动作。真实观察、搜索算法、危险判断、空间记忆和 LLM 均未接入。旧 `Executor` 仍是单独的确定性技能原型，当前不能将两个模块并行连接到同一游戏控制通道。

## 目标与能力

首期目标为持续跟随一个明确玩家 UUID，维持指定距离，不破坏或放置方块，不使用物品、不攻击，也不跨维度追踪。请求人和跟随对象分别记录。距离使用方块单位，具体距离算法与浮点坐标在真实适配阶段校准。

`FollowGoal` 包含 `id`、`target`、`requested_by`、`issued_at`、`expires_at`、`distance_blocks` 和 `search_budget`。时间为调用方提供的同一单调时钟，禁止混用墙上时间。距离和搜索预算必须大于零，发布日期不能晚于现在，有效期必须晚于现在。搜索预算从首次丢失开始计时，临时避险不重置预算；恢复目标可见后，本次搜索结束。

首期完成条件固定为持续型。靠近目标、完成一次寻路、看见村庄都不会完成目标；玩家结束产生取消，期限到达产生过期失败。未来支持「到达村庄」时需新增明确位置或可验证区域条件。

适配器声明 `observe_players`、`navigate_without_modification`、`confirmed_cancel`。缺少任一能力时拒绝接纳目标。能力只声明接口保证，地形可通行性、观察过滤、活动范围和具体动作参数仍须由运行时校验。权限扩大必须扩展类型和检查，不通过文本解释暗中授权。

## 标识与所有权

| 标识 | 语义 |
| --- | --- |
| session | 每次连接、出生或世界切换后的上下文标识，由宿主保证不复用 |
| revision | 会话内决策上下文版本，接纳目标、停止、阶段变化或开始动作取消时递增 |
| goal id | 业务任务身份，恢复同一任务可以保留，不能单独用于判断决策是否有效 |
| observation sequence | 当前会话内严格递增的观察序号，附采集时刻 |
| action id | 当前契约实例内递增，与 session 联合确定动作身份 |

主脑和策略返回其读取的 Context（session、revision）。目标替换或停止后旧上下文失效，即使目标 ID 相同也必须拒绝。策略还携带观察序号，首期只接纳最新观察的结果，并在执行前检查年龄；未来允许滞后窗口时需单独验证。

一次最多一个动作拥有控制权。替换目标之前先取消旧动作；收到匹配会话和动作的 `Stopped` 后才接纳新目标。`Finished` 与 `Stopped` 分别处理，取消竞争中的完成不能证明控制已停止。重复、错误动作和旧会话的回执不能释放当前控制权。

宿主先校验动作参数，再调用 `reserve_action` 原子校验来源和预留动作 ID，然后提交适配器。提交失败必须确认未启动或完成停止握手，不能直接复用控制权。新会话只能在旧适配器已销毁或控制已确认释放后创建。

## 阶段与反馈

目标接纳成功进入 Following。当前阶段和目标状态分别表达，Searching、Avoiding 属于执行子状态，Blocked 和 Paused 保留目标但禁止自主续跑。

| 当前阶段 | 事件与判据 | 下一阶段与反馈 |
| --- | --- | --- |
| Following | 目标可见且距离合适 | 保持 Following，等待或注视，进度可合并 |
| Following | 新鲜观察中目标不可见 | Searching，反馈 TargetMissing，使用最后已知位置 |
| Searching | 再次观察到正确目标 | Following，反馈 TargetRecovered |
| Searching | 搜索预算到达、没有允许的搜索动作或无法继续 | Blocked，反馈 SearchExhausted 或 PathUnavailable |
| Following / Searching | 确认当前危险，需要避让 | Avoiding，反馈 DangerStarted，保存恢复阶段 |
| Avoiding | 危险解除且目标、搜索预算及环境已重新校验 | 恢复先前阶段，反馈 DangerEnded；必要时立即转 Searching / Blocked |
| 执行中 | 无法完成避险或恢复条件不成立 | Blocked，反馈 RecoveryUnavailable |
| 任意非终态 | 玩家要求暂停或观察过期 | Paused，反馈 PlayerPaused 或 ObservationExpired |
| Paused / Blocked | 新鲜观察、目标恢复或危险解除 | 保持原阶段；需要主脑或玩家明确重新接纳目标 |
| 任意阶段 | 玩家停止、期限到达、断线或会话切换 | 撤销目标，取消动作，反馈 Cancelled / Expired / SessionEnded |

阶段切换首先取消原动作并更新 revision。取消未确认时，不发布新动作。停止超时进入 StopUnconfirmed 故障锁定，即使目标已撤销也保留动作归属，等待确认或销毁旧会话。上表事件判据由后续运行时生成，`signal` 仅实现状态转换，不判断地形、危险或计时。

反馈统一包含 session、revision、goal id、发生时刻、原因和依据观察；动作反馈另附 action id。进度可覆盖合并，状态转换与终态按会话内递增事件序号处理和去重。发送队列有界，溢出时保留最新状态快照及终态，主脑可重新读状态。此反馈封装及队列在后续主脑接入阶段实现，当前以状态返回和事件序列固定语义。

## 异步与实时边界

主脑请求在后台进行，不暂停既有合法目标。玩家停止直接更新 revision、撤销目标并发起取消，无需等待主脑或策略。旧主脑结果晚到时拒绝，不能把已经停止的任务重新启动。

观察按序接收，重复观察不能刷新采集时刻。宿主串行调用契约并使用单调时间。策略决策超过新鲜度预算、目标过期、目标阶段禁止动作或已有动作占用控制时拒绝预留。期限或观察过期时，宿主必须主动触发撤销或暂停并取消在途动作，不能只等待下一次模型建议。具体定时器和延迟预算属于真实接入项。

## 离线验收序列

`crates/anvil-agent/tests/contract.rs` 覆盖以下公开行为，使用人工时钟和本地事件，没有真实 Minecraft 或 LLM 请求。

1. 主脑长时间未返回，实时侧仍可连续预留和完成动作；停止后主脑旧结果拒绝。
2. 替换目标在取消确认前拒绝；竞争完成、旧会话或错误动作回执不能释放控制。
3. 旧观察、重复观察、过期目标、能力缺失均不能启动动作。
4. 跟随、丢失、搜索、危险、恢复、阻塞和暂停按表转换；阻塞或暂停不会因普通观察自动恢复。
5. 阶段切换使在途策略失效并取消动作；危险解除不能恢复已被玩家停止的任务。

后续真实验收再补充目标位置记忆、搜索预算计时、避险路径、停止尾延迟和断线期间控制清理。
